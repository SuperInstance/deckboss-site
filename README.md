# deckboss.site

Two sites, one product story, Cloudflare Pages:

- **deckboss.ai** — the product: the back-deck pipeline. Cameras learn species ID from the crew's own sorting (tote = label), cross-camera timestamp handoffs (underwater → surface → tote), sounder self-training via hook-count depth (30 hooks, 1.5 fathoms), overnight autotrain + daily A/B, hanging-scale weight capture, best-shot review from the wheelhouse. Undersell, overdeliver.
- **deckboss.net** — technician-facing: training courses, camera-rig rental (training-rig stereos that get removed when the model is good enough), deployment for working vessels.

Built by the fleet (Lucineer + crew), grounded in quilt: cells, not pipelines. See ai-writings/research (back-deck papers) for the full spec.
